# 쇼츠 규격 (No.5 로 확정된 구성)

- **형식**: 1080×1920 (9:16), 30fps, H.264/AAC. 나레이션 + 배경음악 + 자막 + 끝 화면. 길이 약 50~60초(나레이션 약 43~55초 + 끝 화면 6초).
- **장면 6개 + 끝 화면**
| 장면 | 역할 | 분량 | 화면(No.5 예) |
|---|---|---|---|
| S01 훅 | 질문 + 큰 숫자 | 약 4초 | "대출 한도가 1억 넘게 줄었다?" 숫자 카운트다운 |
| S02 개념 | 핵심 개념 1개 | 약 8초 | 금리 막대 위에 가산금리가 얹히는 도식 |
| S03 구간 | 해당 구간·적용 범위 | 약 10초 | 카드 3장이 말하는 순서로 등장 |
| S04 내 숫자 | 예시 계산 결과 | 약 7초 | 막대 3개(반영 전·수도권·지방) |
| S05 체크 | 확인할 것 3가지 | 약 4초 | 체크박스 3개가 차례로 체크 |
| S06 마무리 | 내 조건으로 점검(CTA) + 면책 | 약 9초 | 프롬프트 안내, "※ 예상치예요…" |
| 끝 화면 | "돈버프에서 자세한 내용을 확인해보세요" + 구독/좋아요 | 6초 | 버튼이 눌리는 연출 |
- **분량**: tts 약 270음절. 60초를 넘으면 문장을 줄인다(글자 크기를 줄이지 않는다).
- **줄(line) 단위**: 자막 한 장 = 줄 하나(2~3줄 표기, 한 줄 15자 안팎). 쇼츠 자막 폰트 50px.
- **숫자**: 카드와 같은 값·표기, 소리 나는 대로 tts. 화면 숫자는 카운트다운 후 최종값에서 멈춘다.
- **CTA**: 카드뉴스 마지막 장과 같은 목적지(프롬프트 번호 또는 계산기). 링크는 설명란(쇼츠 화면에는 "설명란 링크").
- **템플릿**: `assets/examples/issue005/anim_shorts.tpl.html`(장면 요소는 `s1…s7` id, 등장 시점은 `a(줄번호)+오프셋`). 새 호는 문구·숫자·막대 높이를 바꾸고 장면별 시각 요소(도식·카드·막대)를 호 내용에 맞게 교체한다.
