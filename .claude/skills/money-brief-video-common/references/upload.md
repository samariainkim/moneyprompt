# 업로드 자료 (assets/upload_materials.example.md 참고)

Claude 는 영상이 확정되면 최종 업로드 자료를 만들어 준다. **게시는 사용자가 유튜브에서 직접** 한다.

- **제목 후보 3개**(롱폼) / 2개(쇼츠): 질문형·정보형. 쇼츠는 `#shorts`.
- **썸네일 문구**(롱폼): 큰 글씨(핵심 숫자 + 물음표) + 작은 글씨(주제·예시 조건). 이미지는 본편 시안 화면을 바탕으로. 캐릭터가 생기면 표정 + 숫자 + 문구 3요소.
- **설명란**: 한 줄 요약 + 면책 + 링크(UTM) + 챕터(롱폼) + 출처 + 일반 면책 + 해시태그.
  - 링크 UTM: `?utm_source=youtube&utm_medium=video|shorts&utm_campaign=brief_no<호>&utm_content=long|shorts`. 카드뉴스 CTA 와 같은 목적지(프롬프트 `/prompt/?p=<번호>` 또는 계산기)로.
  - 챕터: `python3 chapters.py timeline.json video.json` 결과를 쓴다(첫 챕터 0:00, 3개 이상, 각 10초 이상). **uncertain 장면의 챕터 시각은 사용자가 시청 후 확인**하도록 알린다.
  - 발행일·기준일은 적지 않는다(적용 기간은 가능).
- **고정 댓글**: 예시 조건(소득·금리·기간 등)과 면책, 링크.
- **태그**: 주제 키워드 6~8개.
- 합성 음성 공개 항목 안내.
