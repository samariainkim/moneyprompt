# 두 단계 진행 규칙 (쇼츠·롱폼 공통)

사용자가 정한 방식이다. **1단계는 "최종 컨펌 요청"까지만, 2단계는 사용자의 명시적 제작 요청 후에만.**

## 1단계 — 기획 + 제작 세트 (시작: 주제 + 영상 제작 요청)
**만드는 것**
- **기획안(`plan.md`)**: 목적·호, 형식·길이, 제목 후보·썸네일 문구, 장면 구성(장면표), 핵심 숫자와 카드 근거, 업로드 자료 초안, 확인하지 못한 것, 사용자가 준비할 파일, 컨펌 요청 항목. 템플릿 `assets/plan.template.md`, 뼈대는 `pre_production.py` 가 자동 생성.
- **제작 세트**: 대본·장면표(script.md), 장면별 TTS 입력 대본(tts/), TTS 지시문(tts_style.txt), 자막 가안(draft.srt), 화면 시안(정지 이미지), 만드는 방법(TTS 가이드), 업로드 자료 초안.
**하지 않는 것**: 영상(mp4) 렌더링·완성본 전달, 음성 합성, 유튜브 관련 게시.
**끝맺음**: 컨펌이 필요한 항목, 사용자가 만들 파일 목록, "검토와 파일 준비가 끝나면 **'최종 영상 제작'을 요청해 주세요**"를 적고 멈춘다.

## 2단계 — 최종 영상 제작 (시작: 사용자의 명시적 제작 요청)
- 사용자가 검토를 마치고 음성(장면별 wav 권장)·배경음악 등 **필요한 파일을 만들어 전달한 뒤 "최종 영상 제작"을 요청**하면 그때 `make_video.py` 로 영상을 만든다.
- **파일이 업로드됐다는 것만으로는 시작하지 않는다.** 파일은 받아 두고 누락·이상만 점검해서 알린 뒤, 제작 요청을 기다린다.
- 결과(mp4·srt·확인 프레임)와 확인이 필요한 점(uncertain 장면 등)을 한 번에 보고 → 사용자 검수 → 수정 → 업로드 자료 확정.

## 단계 사이의 규칙
- 1단계 중 수정 요청 → 기획안·세트를 고쳐 **다시 컨펌 요청**(2단계로 넘어가지 않는다).
- 2단계 중 새 내용·방향 변경(대본·구성 변경) → 1단계로 돌아가 컨펌을 받은 뒤 반영. 단순 오탈자·자막 시각 조정은 요청받은 부분만 수정.
- 사용자가 샘플이나 일부 장면 영상을 명시적으로 요청한 경우(예: 샘플 제작)는 그 요청 범위만 만든다.
