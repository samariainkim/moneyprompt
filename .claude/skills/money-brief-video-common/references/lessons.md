# 실제 겪은 함정 (No.5 쇼츠·롱폼 제작)

- **한 파일로 받은 나레이션**은 장면 경계(긴 쉼)는 잘 맞지만 장면 안 줄 경계는 어긋날 수 있다(체크리스트 "하나, 둘…"처럼 끊어 읽는 구간). → 처음부터 장면별 음성을 요청한다.
- **자막과 도형이 겹침**: 롱폼 본문이 y≈800 을 넘으면 2줄 자막과 겹친다. 쇼츠는 자막이 y≈1500~1610. 시안(storyboard.py)에서 반드시 눈으로 확인한다.
- **긴 라벨 줄바꿈**: "수도권·규제지역" 같은 라벨이 막대 폭 때문에 두 줄로 꺾였다 → `white-space:nowrap`, 막대 폭 조정.
- **숫자 끝자리**: 애니메이션 중간값(카운트다운)이 스크린샷에 잡혀 "다른 숫자"처럼 보일 수 있다. 확인 프레임은 카운트가 끝난 뒤 시점으로 본다.
- **글꼴 경로**: 템플릿은 작업 폴더의 `fonts/node_modules/pretendard/...` 를 읽는다. 다른 폴더에 둔 템플릿은 글꼴이 안 나와 기본체로 렌더된다 → `make_video.py` 는 작업 폴더에 템플릿을 복사해 쓴다.
- **쇼츠 길이**: 첫 대본(약 71초)이 60초를 넘어 문장을 줄였다. `pre_production.py` 가 60초 초과 시 경고한다.
- **배경음악 길이**: 61초 곡으로 롱폼(3분 39초)을 채우려면 이어 붙이기가 필요하다(`mix_audio.sh` 가 자동 처리, 이음새 3초 크로스페이드).
- **Playwright 렌더 속도**: 워커 4~6개로 쇼츠 약 35초, 롱폼 약 3분(6,500장).
- **영상 도구는 저장소가 아니라 이 스킬 폴더**에 있다. 산출물(mp4·wav·프레임)은 scratchpad 에만 둔다.
