# 나레이션(더빙) 만들기 — Google AI Studio TTS

더빙은 **사용자**가 Google AI Studio 의 음성 생성(TTS) 기능으로 만든다(이 환경에서는 쓸 만한 한국어 음성 합성과 외부 TTS 접속이 안 된다). Claude 는 대본과 지시문을 준비하고, 받은 음성으로 영상을 만든다. 화면 메뉴 이름은 업데이트로 바뀔 수 있으니 흐름 기준으로 안내한다.

## 사용자에게 안내할 순서
1. AI Studio 에서 **음성(스피치) 생성** 기능이 있는 TTS 모델을 고르고 한국어 지원·목소리 목록을 확인한다.
2. **한 가지 목소리**를 정해 쇼츠·롱폼 모두 같은 목소리·설정으로 생성한다(채널 톤 일관).
3. `assets/tts_style.txt` 의 지시문(쇼츠용: 조금 빠르게 / 롱폼용: 설명하듯 천천히)을 먼저 쓰고, 이어서 장면 대본(`tts/S01.txt` …)을 붙여 넣는다.
4. **장면 하나씩** 생성한다(권장). 장면별 파일이 있으면 시간 맞춤이 정확하다(`alignment.md`).
5. 파일 이름은 장면 id 그대로: `S01.wav … S06.wav`(쇼츠), `L01.wav … L09.wav`(롱폼). wav·mp3 모두 가능.
6. 들어 보고 점검: 금액·퍼센트가 대본대로 읽히는지, 영문 약어가 어색하지 않은지, 속도가 장면마다 들쭉날쭉하지 않은지. 어색하면 **대본 txt 의 글자를 바꿔** 다시 생성하고, 바꾼 글자는 Claude 에게 알려 자막과 맞춘다.
7. 배경음악 mp3 는 사용 조건이 확실한 음원으로(`compliance.md`). 한 곡이면 되고 길이가 짧아도 자동으로 이어 붙는다.

## 대본(tts) 작성 규칙 — 소리 나는 대로 한글로
TTS 는 숫자·영문·기호를 틀리게 읽기 쉬워서 `video.json` 의 `tts` 는 읽는 대로 풀어 쓰고, 화면 표기는 `sub` 에 따로 둔다.
| 화면 표기(sub) | 읽기(tts) |
|---|---|
| 6천만 원 | 육천만 원 |
| 4억 898만 원 | 사억 팔백구십팔만 원 |
| 2억 9,464만 원 | 이억 구천사백육십사만 원 |
| 1억 1,434만 원 | 일억 천사백삼십사만 원 |
| 3.0%p | 삼 퍼센트포인트 |
| 0.75%p | 영점 칠오 퍼센트포인트 (쇼츠에선 "영점 칠오"까지만도 가능) |
| 4.2% | 사점 이 퍼센트 |
| 30년 | 삼십 년 |
| 2025년 10월 16일 | 이천이십오 년 시월 십육 일 (6월=유월, 10월=시월) |
| DSR / LTV / DTI | 디에스알 / 엘티브이 / 디티아이 |
- 문장은 짧게, 마침표·쉼표로 쉼을 만든다(쉼이 없으면 시간 맞춤이 어렵다). 한 줄(line)은 자막 한 장에 대응하므로 자막 한 장에 들어갈 길이로 끊는다.
- 쇼츠 예상 길이 약 55~60초(약 270음절), 롱폼 약 3:30~4:00. 음성이 길어지면 문장을 줄인다.
- 카드뉴스에 없는 주장·숫자를 대본에 넣지 않는다.

## 말투
차분하고 신뢰감 있는 30대 경제 해설 톤. 단정·권유("무조건", "사세요") 금지. 쉬운 말, 결론 먼저.
