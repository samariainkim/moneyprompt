# 화면 규격

## 공통
- 색: 오렌지 `#FF7900`, 네이비 `#10233F`, 크림 `#FFF3E6`. 글꼴 Pretendard(작업 폴더 `fonts/` 에 npm 설치 → 템플릿이 `fonts/node_modules/pretendard/...` 를 읽는다).
- 상단 좌측 `MONEY BRIEF · 돈버프`, 상단 진행 막대(주황), 하단 면책 한 줄(예시 계산·예상치·실제 한도는 은행 심사에 따라 달라요 등 호에 맞게).
- 자막은 영상에 입힌다(+ 별도 srt). 배경 박스(네이비 92%)·흰 글씨·굵게.
- 카드뉴스와 같은 어휘·숫자·표기. 화면에 **발행일·기준일을 쓰지 않는다**(사용자 결정). 제도의 **적용 기간**(예: "2026년 하반기 적용")은 정확성을 위해 쓴다.
- 화면 요소는 **줄(line) 번호에 묶어 등장**시킨다(예: 3번째 줄이 시작될 때 카드 등장) → 음성 시간이 바뀌어도 자동으로 따라간다.
- 끝 화면: "돈버프에서 자세한 내용을 확인해보세요" + `donbuff.com` + **구독 버튼이 눌려 "구독중 ✓"(종 흔들림), 좋아요 버튼이 눌려 주황 "좋아요 ♥"**. 유튜브 로고는 쓰지 않는다. 문구 "도움이 되셨다면 구독과 좋아요 부탁드려요".

## 쇼츠 1080×1920 (9:16)
- 안전 영역: 하단 약 310px(유튜브 UI 와 자막), 우측은 버튼 영역이라 중요한 글자를 가장자리에 붙이지 않는다. 자막은 `bottom:310px`, 본문은 y≈1500 아래로 내려가지 않게.
- 길이 55~60초(끝 화면 포함 약 50~65초). 첫 2초에 훅(질문 + 큰 숫자).

## 롱폼 1920×1080 (16:9)
- 자막은 `bottom:120px`(2줄이면 높이 약 160px) → **본문은 y≈800 아래로 내려가지 않게** 배치한다(체크리스트·칩·막대 모두).
- 카드 7장 흐름에 대응: 훅 → 개념 → 변화 → 구간 → 내 숫자 → 한 걸음 더 → 체크리스트 → 마무리(CTA) → 끝 화면.
