# 롱폼 규격 (No.5 로 확정된 구성)

- **형식**: 1920×1080 (16:9), 30fps, H.264/AAC. 나레이션 + 배경음악 + 자막 + 끝 화면. 길이 약 3:30~4:00(No.5: 3분 39초, 나레이션 3분 32초 + 끝 화면 뒤 여유).
- **장면 9개 + 끝 화면** (카드 7장 흐름에 대응)
| 장면 | 역할 | 분량 | 화면(No.5 예) |
|---|---|---|---|
| L01 훅 | 질문 + 핵심 숫자 대비 | 약 20초 | 표지 타이틀 + 숫자 카운트다운 + "?" |
| L02 개념 | 용어 정의 | 약 17초 | DSR = 연간 원리금 ÷ 연소득, 40% 막대 |
| L03 핵심 제도 | 스트레스 DSR | 약 20초 | 실제 금리 + 가산금리 도식, "실제로 내는 금리는 그대로" |
| L04 무엇이 바뀌었나 | 변화 타임라인 | 약 24초 | 카드 4장(시기·값·대상) |
| L05 내 구간 | 해당 구간 확인법 | 약 17초 | 구간 표 + 강조 + 안내 칩 |
| L06 내 숫자 | 예시 계산 | 약 29초 | 가로 막대 3개 + 줄어든 금액 |
| L07 한 걸음 더 | 조건별 비교 | 약 20초 | 기간별 막대 3개 + 주의 칩 |
| L08 체크리스트 | 확인 5가지 | 약 35초 | 체크 항목 5개 + 보조 설명 |
| L09 마무리 | CTA + 면책 | 약 23초 | 프롬프트 안내 + 소득 인정·LTV·DTI… 칩 |
| 끝 화면 | "돈버프에서 자세한 내용을 확인해보세요" + 구독/좋아요 | 약 9초 | 버튼이 눌리는 연출 |
- **분량**: tts 약 1,130음절. 4분을 넘으면 L05·L07 을 줄인다.
- **자막 줄**: 한 장 = 줄 하나(최대 2줄, 한 줄 25자 안팎), 폰트 46px, 하단 120px. 본문은 y≈800 위에.
- **챕터**: 장면 이름 = 챕터(0:00 시작, 10초 이상). 설명란에 적는다.
- **썸네일**: 큰 숫자 + 물음표 + 주제 + 예시 조건(캐릭터가 생기면 표정 포함). 본편 L01 화면 바탕.
- **템플릿**: `assets/examples/issue005/anim_long.tpl.html`(장면 id `L01…L09`, `END`). 새 호는 장면별 시각 요소를 호 내용에 맞게 교체한다.
