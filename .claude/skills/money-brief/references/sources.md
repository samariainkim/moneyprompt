# 수집원과 접근 방법 (2026-11 확인, 바뀔 수 있으니 먼저 시험)

환경 네트워크는 허용된 호스트만 열린다. 막히면 우회하지 말고 **`update_environment` 로 필요한 호스트만 허용 요청**한다(사용자 승인 화면이 뜬다). 지금까지 허용한 호스트: `donbuff.com`, `www.korea.kr`, `www.law.go.kr`, `www.moef.go.kr`, `www.nts.go.kr`, `www.kofia.or.kr`.

## 한 번에 확인된 접근 방법
| 자료 | 방법 | 비고 |
|---|---|---|
| 정책브리핑(korea.kr) 정책뉴스 | `curl -sSL -A "Mozilla/5.0" <주소>` → HTML 에서 `<p>` 본문 추출 | 본문이 HTML 에 있다 |
| 정책브리핑 **보도자료**(금융위·국세청 등) | 페이지 HTML 에는 본문이 없고 **첨부파일**에 있다. HTML 의 `download.do?fileId=<번호>&tblKey=GMN` 를 찾아 `curl -sSL "https://www.korea.kr/common/download.do?fileId=<번호>&tblKey=GMN" -o f.bin` → PDF 면 `pdftotext -layout f.bin f.txt` | hwp/hwpx 는 읽지 않고 PDF 를 쓴다 |
| 국세청 자료 | `nts.go.kr` 은 이 환경에서 **연결이 끊긴다**(허용해도). 정책브리핑에 실린 국세청 보도자료·카드뉴스를 쓴다 | 국세청 원문 대조는 운영자에게 요청 |
| 금융위(fsc.go.kr) | 보도자료 목록은 검색으로 찾고, 본문은 정책브리핑 전재본을 쓴다 | |
| 한국은행·금감원·금융투자협회 | 허용 후 `curl` 로 시도. 검색 요약만 믿지 말 것 | kofia 는 허용했으나 필요한 내용이 없었다 |
| 환율 | `calc/data/fx/rates.json`(한국수출입은행 API, GitHub Actions 자동 수집, `base_date`·`checked_at`) | 주말·공휴일은 직전 영업일 값 |
| 돈버프 계산기·프롬프트 데이터 | 저장소의 `calc/`, `prompt/index.html` | |

## 검색 사용법
- `WebSearch` 는 한국어도 된다. 가능하면 `allowed_domains`(`korea.kr`, `fsc.go.kr`, `moef.go.kr`, `kofia.or.kr` 등)로 **1차 자료 후보**를 찾고, 결과 요약이 아니라 **원문을 열어** 확인한다.
- 여러 검색을 한꺼번에 보낸다. 오래된 자료(작년·재작년)가 섞이므로 날짜를 항상 확인한다.

## 자주 쓰는 1차 자료 유형
- 세금·연말정산: 국세청 보도참고자료·연말정산 미리보기 안내(정책브리핑), 기획재정부(재정경제부) 세제개편
- 대출·수수료: 금융위원회 보도자료(중도상환수수료 개편 2025.1.9, 상호금융 2025.10.22), 금융감독원
- 금리: 한국은행 금통위 결정문·의사록(**결정 이후**에 발행)
- 환전·외환: 한국수출입은행 고시 환율, 외환 관련 금융위·한국은행 자료
- 금융상품 비교: 금융감독원 금융상품통합비교공시(상품 추천으로 읽히지 않게 교육형으로)
