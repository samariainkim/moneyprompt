# 주제 후보 선정 (사용자가 고르기 전까지 제작하지 않는다)

## 목표와 대상
- 서비스 목표: 금융 포털로 나아가기 위한 **킬링 콘텐츠**(검색·공유로 유입 → 재방문 → 돈버프 도구 사용).
- 주 대상: **2040 월급쟁이 재테커.** 보조(B2B): 부동산 중개사·FC 가 고객에게 보낼 수 있는 설명 카드.
- 카드뉴스의 역할은 "읽고 끝"이 아니라 **내 숫자로 계산하거나, 프롬프트로 점검하는 행동으로 이어지는 것**이다(마지막 카드 = CTA).

## 후보를 평가하는 기준 (사용자가 정한 3가지 + 안전)
1. **돈버프 연계성**: 연결할 도구가 있는가.
   - 계산기: 대출 중도상환(`/calc/loan-prepay/`), 환전수수료(`/calc/fx/`), 부동산 중개보수(`/calc/brokerage/`), 증권사 수수료(`/fee/`).
   - 프롬프트: `prompt/index.html` 의 `idx`·`title` 로 짝을 지을 프롬프트를 실제로 찾는다(172개: 주식투자 53, 부동산 39, 절세전략 33, 재테크루틴 24, 지출·저축 11, AI투자팀 7, 재무진단 5). 특정 프롬프트로 바로 연결하려면 `/prompt/?p=06%2F03` 처럼 번호(`idx`)를 쓴다.
   - 투자 성향 검사(`/invest-mbti/`) 연계도 가능(연말 포트폴리오 점검 등).
2. **최신성·화제성**: 지금 시기에 검색·관심이 늘어나는가(연말정산, 금통위, 세법·제도 시행일, 환율 변동 등). 날짜가 정해진 이벤트는 **발행 시점**을 함께 제안한다(예: 금통위는 결정 이후).
3. **관심도**: 2040 월급쟁이가 자기 돈으로 느끼는가(세금·대출·환전·저축).
4. **검증 난이도·법적 리스크**: 1차 자료로 확인 가능한가, 상품 추천으로 읽힐 위험은 없는가(적금 최고금리 비교는 "조건 읽는 법" 교육형으로만).

점수는 ★1~5 의 **전략적 추정**임을 표시하고(측정값이 아님), 검색량 등 실측이 필요한 항목은 "확인 불가"로 둔다.

## 보여 주는 형식 (표 + 추천 + 선작업)
| # | 주제 | 형식 | 연결 도구 | 왜 지금인가 | 연계·시의성·관심 | 검증 난이도 |
- 형식: **뉴스**(정책·제도 변화), **정보**(구조·개념 설명, 뉴스 근거가 약할 때), **체크리스트**.
- 카드 카테고리 표기는 `분류 · 주제` ("뉴스 · 정책변화", "정보 · 환전", "뉴스 · 연말정산").
- 추천 2편을 이유와 함께 제시: **계산기 연동 1편 + 프롬프트 연동 1편**처럼 서로 다른 연결로 균형을 맞춘다.
- 선작업 목록: 원문 확인에 필요한 자료·도메인 허용, 결과가 나와야 쓸 수 있는 주제(금통위 등)의 발행 시점, 연결할 계산기가 없을 때 필요한 개발.

## 지금까지의 호 (중복 방지, `web/redesign/data/brief.json` 참고)
- No.1 중도상환수수료(뉴스 · 정책변화) → 계산기 · No.2 환전(정보) → 계산기 · No.3 연말정산(뉴스) → 프롬프트 `06/03`
- 후속 후보로 남은 것: 금통위 결과와 내 대출(결정 이후 발행), 적금 최고금리의 함정(교육형), 연말 포트폴리오 점검(세금 고려 리밸런싱), 상호금융·새마을금고 중도상환 후속, 나만의 경제 브리핑 만들기(프롬프트 소개).
