# 블로그 게시글 확정 형식 (No.1 샘플로 확정)

## 구성 (순서 고정)
1. **제목**: `<카드 표지 질문/제목> | 돈버프 MONEY BRIEF No.<N>`
2. **도입 3줄**: "안녕하세요. 사마리아인입니다." → 뉴스/상황을 묻는 훅 한 줄("…보셨나요?") → "카드 7장으로 정리했습니다."
3. `[카드 1]` ← 대표 이미지
4. **카드 2~6**: 굵은 소제목(`**① …**`) + 1~3문장 + `[카드 N]`. 카드 순서대로.
   - 카드 6(체크리스트)은 이미지 뒤에 항목을 `·` 목록으로 한 번 더 적는다(저장·검색용).
   - 카드 이미지 속 글자는 검색에 안 잡히므로 핵심 문장·숫자를 글로도 쓴다. 카드와 같은 숫자.
5. **카드 7(CTA)**: 행동 유도 한 줄 + `[카드 7]` + `👉 <도구 이름>` + 링크(UTM).
6. **연재 안내**: "MONEY BRIEF는 인스타그램·쓰레드에서도 같은 카드로 만나보실 수 있습니다." + `/brief/` 링크(UTM). 다음 호 예고 한 줄.
7. **마무리**: "도움이 되셨다면 공감과 이웃추가 부탁드립니다. 감사합니다."
8. **하단 고정 블록**(구분선 아래): `출처: … · 계산 … · 기준일 YYYY.MM.DD` / `※ 면책 한 줄` / 해시태그 7~10개(주제 + `#금융정보 #카드뉴스 #머니브리프 #돈버프`).

## 링크 (UTM)
- 도구/프롬프트/특집 링크: `…?utm_source=naver_blog&utm_medium=blog&utm_campaign=brief_no<N>`(프롬프트 링크는 `?p=…` 뒤에 `&utm_…` 로 이어 붙인다)
- 사이트 모아보기: `https://donbuff.com/brief/?utm_source=naver_blog&utm_medium=blog&utm_campaign=brief_no<N>`
- 호별 도구 링크는 `brief.json` 카드 7 `link.href` 를 따른다.

## 카드 → 소제목 매핑 (7장 구성 기준)
| 카드 | 역할 | 소제목 예 |
|---|---|---|
| 1 | 표지 | (대표 이미지, 소제목 없음) |
| 2 | 무엇이 달라졌나/상황 | ① 무엇이 달라졌나 |
| 3 | 누구에게·핵심 | ② 내 경우도 해당될까? |
| 4 | 계산/핵심 숫자 | ③ 내 돈으로 바꾸면 |
| 5 | 한 걸음 더 | ④ 이것도 알아두세요 |
| 6 | 저장용 체크리스트 | ⑤ 저장해 두세요 |
| 7 | CTA | ⑥ 직접 해보세요 |
호에 따라 카드 2~5 의 종류가 다르면 카드 제목에 맞춰 소제목을 바꾼다.

## 이미지셋
- 파일명 `card_01.png ~ card_07.png`, 1080×1350 PNG, ZIP 이름 `MONEYBRIEF_No<N>_blog_images.zip`.
- 올릴 때 안내: 한 번에 선택해 순서대로, 카드 1 대표 지정, 이미지 설명(대체 텍스트)에 카드 제목.

## 분량·톤 요약
- 합쇼체, 짧은 문장, 한 문단 1~3문장, 본문 약 1,300자. 군더더기·광고 문구 금지.
- 더 줄여야 하면 카드 5 설명을 뺀다(약 1,100자). 카드 제목만 쓰면 700~800자(검색에는 불리).
