# MONEY BRIEF 블로그 게시글 + 이미지셋

호 번호(또는 주제)를 받으면 `references/format.md`(확정 형식)를 읽고 `references/sample-no1.md`(확정 샘플)와 같은 형식으로 쓴다.

## 진행 순서
1. **호 데이터 확인.** 사이트에 발행된 내용이 기준이다: `web/redesign/data/brief.json` 의 해당 호 카드 `alt`(카드 속 글자 전체), `base_date`, `link`. 숫자·문장은 카드와 **똑같이** 쓴다(카드에 없는 주장 금지). 작업 폴더가 scratchpad 에 남아 있으면 `edition.json`, `verify-*.md` 도 함께 본다.
2. **게시글 작성** → scratchpad 의 `MONEYBRIEF_blog_No<N>_<slug>.md`. 형식은 format.md.
3. **이미지셋 만들기.** 카드 PNG 7장(1080×1350)을 `card_01.png ~ card_07.png` 로 이름을 맞춰 `MONEYBRIEF_No<N>_blog_images.zip` 으로 묶는다.
   - 원본 위치: 작업 폴더 `brief-NNN/out/01~07.png` 또는 `brief-NNN/export/…/0N.png`(없으면 사이트 JPG `web/redesign/img/brief/<id>/` 를 쓰되 PNG 가 아님을 알린다).
   - 호가 갱신(`publish.py --replace`)된 적이 있으면 사이트 카드와 PNG 가 같은지 확인한다.
4. **사용자에게 전달.** `SendUserFile` 로 게시글 `.md` + 이미지 ZIP 을 보내고, 한 메시지에: 글의 구성 요약, 올릴 때 참고(이미지 순서·대체 텍스트·대표 이미지 = 카드 1), **기준일이 지나 갱신이 필요한지**(No.6 은 12/18 이후, No.4 는 11월 공시 후, No.5 는 12월 스트레스 금리 갱신 후)를 적는다.
5. 저장소에 파일을 커밋하지 않는다(요청 시에만). 작업물은 scratchpad.

## 지켜야 할 것
- 문체: 합쇼체("~입니다/~했습니다/~보세요"), 인사 "안녕하세요. 사마리아인입니다.", 마무리 "도움이 되셨다면 공감과 이웃추가 부탁드립니다. 감사합니다." 이모지는 링크 앞 👉 정도만.
- 짧게: 본문 1,300자 안팎(공백 포함). 카드 한 장당 1~3문장. 카드와 중복되는 긴 설명 금지.
- 금융 안전: 특정 상품·금융사 추천, 수익 보장, 단정 표현 금지. 면책·출처·기준일 필수. 개인정보 금지.
- 호의 한계(작년 기준 수치, 단일 출처, 기간 종료일 등)를 글에서 더 단정적으로 쓰지 않는다.
- 사이트·SNS 와 숫자·기준일이 다르면 안 된다.
