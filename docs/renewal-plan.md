# 디자인·UX/UI 전면 리뉴얼 기획 메모 (보류 중)

**상태: 도메인 전환(본 페이지 이전)과 안정화가 끝난 뒤에 시작한다.** (결정일 2026-11-12)

## 결정한 것
- **순서:** ① 도메인 전환 마무리 → ② 안정화 → ③ 디자인 리뉴얼. 전환 때는 지금 모습 그대로 옮긴다. (트래픽 변화의 원인을 분리하고, 페이지 단위 배포로 롤백을 쉽게 하기 위해)
- **방식:** 한꺼번에가 아니라 **페이지별로 하나씩**, 시안 확정 후 배포.
- **병행 가능:** 디자인 시스템 기획·시안은 전환 작업과 겹치지 않으므로 먼저 해도 된다. 구현은 안정화 후.
- **페이지 순서(제안):** 메인 → 금융계산기 목록(`/calc/`) → 개별 계산기 → 프롬프트 → 투자 성향 → 로그인·안내(`/join/`)·계정.

## 레퍼런스
- 스튜디오제이티의 카카오엔터프라이즈 웹사이트 리뉴얼 (https://www.studio-jt.co.kr/projects/kakao/). 본문은 못 읽었고 스크린샷만으로 분석함.
- 가져올 것: 얇은 상단 바·메뉴 수 절제, 서비스를 색이 다른 정사각 타일로 보여주기, 콘텐츠 카드(분류 라벨·해시태그 칩), 알약형 버튼 한 가지 스타일, 넉넉한 여백과 큰 영문 슬로건 대비, 단순한 푸터.
- 그대로 안 가져올 것: 풀블리드 사진 히어로·마스코트 의존. 돈버프는 첫 화면에서 **도구를 바로 쓰게 하는 것**이 핵심(레퍼런스는 문의를 받는 B2B 소개 사이트).

## 색상 기준
- 시그니처: **돈버프 오렌지**. 면적을 작게(버튼 면, 강조 타일, 포인트 라벨).
- 본색: **검정·흰색**, 명도 단계(예: 10단계 회색 스케일)로 배경·글자·구분선을 맡긴다.
- 주의: 현재 오렌지(#d97706)는 흰 배경 위 작은 글자에서 대비가 약 3:1로 낮다. 글자용 진한 오렌지를 따로 두고 밝은 오렌지는 면에만 쓴다.

## 시작할 때 할 일
1. 도메인 전환 체크리스트 문서 (Vercel 플랜, DNS·이전 주소 연결, Supabase·구글 로그인 주소, Search Console, 환율 자동 갱신 재배포).
2. 디자인 시스템 기획서: 색 토큰, 타이포, 버튼, 카드, 칩, 타일, 헤더·푸터.
3. 메인 페이지 시안(A/B안) → 선택 후 구현.
