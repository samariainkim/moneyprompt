# 돈버프 디자인 시스템 · 메인 리뉴얼 확정안 (C안) v1.0

- **상태:** 메인 페이지 시안 **확정** (2026-11-15). 실제 사이트 적용은 **도메인 전환 후 안정화(약 2주, 2026-11-26 전후)가 끝난 뒤** 페이지 단위로 진행한다. (`docs/renewal-plan.md` 순서 참고)
- **시안 파일:** `docs/design/main-mockup-c-final.html` — 브라우저로 열면 확정 시안을 볼 수 있다(창 폭을 바꾸면 반응형 확인, ☰ 메뉴·금융계산기 메뉴 동작). 참고용 목업이며 서비스 코드가 아니다.
- **적용 범위:** 이 문서는 메인 페이지에서 정한 기준을 사이트 전체의 기준으로 확장한다. 하위 페이지(금융계산기 허브, 프롬프트 등)는 같은 기준으로 시안을 만들어 확정한다.

## 1. 디자인 방향
밝고 깔끔한 금융 서비스. **블랙/네이비와 오렌지는 포인트**로만 쓰고, 바탕은 화이트·오프화이트·크림이 맡는다. 오렌지가 과하면 쇼핑·프로모션 플랫폼처럼 보이므로 면적을 아낀다. 레퍼런스(카카오엔터프라이즈 등)에서 가져온 것: 얇은 헤더, 큰 타이포 대비, 서비스를 카드·타일로 보여주기, 알약형 버튼, 넉넉한 여백.

## 2. 컬러 시스템
| 이름 | 값 | 역할 |
|---|---|---|
| Brand Orange | `#FF7900` | 브랜드 에너지·행동 유도(주 버튼, 심볼, 강조 면) |
| Orange 600 | `#E56A00` | 오렌지 hover·눌림 |
| Orange Text | `#C25A00` | **흰/크림 바탕 위 작은 오렌지 글자**(대비 확보) |
| Deep Navy | `#10233F` | 신뢰·전문성(제목, 푸터, 보조 카드, 주 텍스트) |
| Navy 2 | `#1B3A66` | 네이비 그라디언트 보조 |
| Warm Cream | `#FFF3E6` | 친근함(카드 바탕, LAB 배경) |
| Hero Cream | `#FFF2E5` | 히어로 배경(대안 `#FFF5EB`) |
| Off White | `#FAFAF8` | 일반 섹션 바탕(정보 전달) |
| Outside | `#ECEAE5` | **사이트 틀(1200px) 바깥 배경**, 웜 그레이 확정 |
| Muted | `#5E6B80` | 보조 글자 |
| Line | `#E8E6E0` | 구분선·테두리 |

값은 제안안이며 기존 사이트의 토큰을 추출한 값이 아니다(기존 사이트 네이비는 `#0B1A2B`, 오렌지 `#FF7A00`). 적용 때 한 파일(CSS 변수)에서 관리한다.

**사용 규칙**
- 오렌지 바탕 위의 작은 글자는 **네이비**로 쓴다(흰 글자는 대비 부족). 큰 제목만 예외적으로 흰색 가능.
- 한 화면에 **오렌지 큰 면은 하나**만 둔다(예: 프롬프트 카드). 큰 오렌지 원·연속 오렌지 카드는 쓰지 않는다.
- 네이비 면이 연달아 나오면 무거우므로 사이를 띄우고 그라디언트(`#1B3A66→#10233F`)로 톤을 바꾼다.
- 이미지·캐릭터는 포인트. 색을 늘리지 않는다.

## 3. 레이아웃·폭
| 항목 | 기준 |
|---|---|
| **사이트 틀 최대폭** | **1200px**, 가운데 정렬. 히어로·LAB·푸터 등 **모든 배경도 틀 안에서 끝난다**(와이드 모니터에서 배경이 끝없이 늘어나지 않음). 틀 바깥은 Outside 색, 틀에는 아주 옅은 테두리·그림자 |
| **콘텐츠 폭** | **1140px** (틀 안 좌우 여백 30px, 모바일 20px) |
| **본문·도구 읽기 폭** | **760px** (계산기 입력·결과, 이용약관·개인정보처리방침 등 긴 글), 가운데 정렬 |
| **입력·검사 폭** | **480px** (로그인·가입·계정·`/join/`, 투자 성향 검사 진행) |
| **중단점** | 900px / 640px (히츠브랜드랩 기준 준용). 모바일 설계 기준 390px |
| **헤더·푸터** | 모든 페이지에서 같은 틀·같은 정렬선 |
| **히어로 높이** | 좌측 타이틀 블록 높이와 우측 일러스트 높이를 맞춘다(현재 약 650px) |

현재 사이트는 홈·프롬프트·계산기 900px, 회원 앱 960px이다. 적용 때 모든 페이지를 데스크톱·모바일에서 전후 비교로 확인한다.

## 4. 타이포그래피
- 서체: **Noto Sans KR** (300·400·500·700·900). 한글 줄바꿈은 `word-break: keep-all`.
- 히어로 제목: "돈에 AI를"은 **얇게(300)**, "**더하다**"는 **굵게(900)**, 마침표는 오렌지. 데스크톱 88px / 모바일 54px.
- 섹션 제목 38px(모바일 28px)·900, 카드 제목 32px(카테고리 23px)·900, 본문 16~17px, 라벨(영문 대문자) 12~13px·900·자간 넓게.

## 5. 컴포넌트
- **버튼:** 알약형(둥근 끝). 주 버튼=오렌지 바탕+네이비 글자 / 보조=네이비 테두리 / 어두운 면의 CTA=오렌지 / 헤더 로그인=네이비 바탕+흰 글자.
- **카드:** 모서리 크게(서비스 32px, 카테고리 26px, 작은 카드 20~24px). hover 시 살짝 위로.
- **말풍선(히어로):** 흰 바탕+그림자, 일부 네이비 바탕. 꼬리는 모서리 비대칭 처리. 질문 5개.
- **태그·칩:** 작은 알약/모서리 8px, 개수·특징 표시.
- **헤더:** 기존 로고(오렌지 AI 심볼+DONBUFF, **투명 배경 원본 필요**), 메뉴 `돈 버는 프롬프트` / `나의 투자성향 찾기` / `금융계산기 ▾`(부동산 중개보수·대출 중도상환·환전수수료·전체 보기), 로그인 시 `내 계정 ▾`(내 결과·즐겨찾기 프롬프트·프로필 설정·로그아웃). 모바일은 ☰ 전체 화면 메뉴. **아직 공개되지 않은 서비스는 메뉴에 노출하지 않는다.** 확장 가능한 구조로만 설계.
- **푸터:** 기존 정보 유지 — 돈버프(DONBUFF), 『AI로 부자되기』 저자 김태형(사마리아인), donbuff.com·사마리아인TV·돈버프 금융계산기·독자 오픈채팅방·협업·강연 문의, "금융계산기 결과는 참고용이며, 최종 의사결정은 이용자 본인에게 있습니다." 네이비 바탕. 클로징에 로고(전체형) 노출.

## 6. 메인 페이지 구성 (확정)
1. **히어로** (전체 폭 연한 오렌지 띠, 틀 안)
   - DONBUFF · AI FINANCE / 돈에 AI를 **더하다**. / 내 돈에도 버프가 필요하니까. / 복잡한 금융 고민, 직접 계산하고 AI에게 질문하며 더 똑똑하게 관리하세요. / [금융계산기 시작하기] [AI 프롬프트 둘러보기]
   - 우측: 돈버프 로고 카드를 가운데 두고 동전·돈주머니·계산기와 **질문 말풍선 5개**("환전 수수료 얼마나 나가는 거지?" / "어떤 프롬프트를 써야 하지?" / "중개보수 수수료 맞게 낸 걸까?" / "지금 대출을 유지하는 게 나을까?" / "연말정산 환급을 더 받으려면 어떻게 해야 하지?"). 외곽 박스 없이 배경 위에 떠 있는 구성. 소제목(부동산, 환전 등)은 쓰지 않는다.
2. **SERVICES** — 카드 2개, 내용·구성은 기존 사이트 그대로 + 배경만 오렌지/네이비
   - PROMPT BUFF(오렌지): 책→프롬프트→AI 도구 흐름 이미지, "BOOK → AI", 태그(172 PROMPTS·바로 복사·예제파일), [프롬프트 둘러보기 →]
   - INVEST BUFF(네이비): 투자 유형 캐릭터 5장 묶음, "당신은 이들 중 누구일까요?", 태그(16 TYPES·5 MIN·AI DEEP DIVE), [테스트 시작하기 →]
3. **CALC BUFF** — 네이비 와이드 배너(기존 구성): 돈버프 금융계산기 / 돈을 불려주는 스마트한 금융 계산기 / 계산에서 끝나지 않고, AI 심층분석까지. / 부동산 중개보수·대출 중도상환·환전수수료 / [금융계산기 둘러보기 →]
4. **프롬프트 카테고리** — **주요 4개**(주식투자·부동산·절세전략·재테크루틴)만 노출하고 [전체 보기 →]로 연결. **개수는 프롬프트 데이터에서 자동 계산**(수동 입력 금지). 추후 커뮤니티가 생기면 이 영역을 확장·대체할 수 있도록 독립 섹션으로 설계.
5. **DONBUFF LAB** — 크림 배경, 같은 크기 카드 3개(소비습관 BUFF·포트폴리오 BUFF·FIRE BUFF), 라벨은 **`IN THE LAB`** 유지(`COMING SOON` 금지: 출시 준비 중이 아닌 실험 중). "새로운 버프가 계속 추가됩니다."
6. **클로징 로고 + 푸터**

## 7. 이미지·에셋 규칙
- **투자 성향 캐릭터 이미지는 "나의 투자 성향 찾기" 카드(와 검사 결과)에서만** 쓴다. 다른 영역에 돌려 쓰지 않는다.
- 프롬프트 카드는 기존 흐름 이미지(책→프롬프트→AI 도구)를 쓴다.
- **로고:** 기존 DONBUFF 로고 유지. 시안에서는 흰 배경을 투명하게 가공한 임시본을 썼으므로 **투명 배경 원본(SVG/고해상도 PNG) 필요**.
- **히어로 오브젝트(동전·돈주머니·계산기)·카테고리 아이콘:** 시안용 임시 그림. 실제 적용 전에 전문 제작(3D 오브젝트)으로 교체. 이미지 마련 방식(제작 의뢰/생성/아이콘 세트 통일) **결정 필요**.
- **파비콘(확정, PR 진행):** 탭은 **심볼만(투명 배경)** `favicon.ico`·32px, iOS 홈 화면은 **크림 타일** 180·192px. 512px은 원본 로고를 받은 뒤 추가.

## 8. 적용 시 지켜야 할 것
- URL·검색 구조 유지(디자인만 변경). 안정화 기간 중에는 코드 변경을 최소화한다.
- **GA4 측정 유지:** 기존 이벤트와 `data-ga`·클릭 대상(서비스 카드, 문의 링크, 프롬프트 복사 등)이 새 구조에서도 같은 이름으로 나가야 한다(`docs/analytics-audit.md`).
- 로그인 게이트·결과 저장·즐겨찾기 동작은 그대로. 회원 메뉴는 `내 계정 ▾`로 통합.
- 페이지 단위로 배포하고 전후 비교 후 다음 페이지로. 문제 시 해당 페이지만 되돌린다.
- 접근성: 오렌지 위 글자 대비, 포커스 표시, 모바일 터치 크기(44px 이상).
