# MONEY BRIEF(카드뉴스) 운영 지침

돈버프의 금융 카드뉴스 서비스(`donbuff.com/brief/`)를 만들고 운영하는 방법. 사람이 읽는 요약이고, Claude 가 따르는 상세 절차는 `.claude/skills/money-brief/SKILL.md` 에 있다.

## 한 줄 사용법
Claude 에게 **"돈버프 카드뉴스를 제작해줘"** 라고 하면 `money-brief` 스킬이 아래 순서로 진행한다.

1. **주제 후보 리스트업**(표) → **사용자가 하나를 고름**
2. 1차 자료 원문 확인 → 숫자는 계산 엔진으로 계산(독립 검산) → 카드 7장 제작
3. **검증 보고서**와 함께 최종 시안 보고 → 사용자가 검수·수정 요청
4. 확정되면 브랜치에 반영 → 테스트 환경에서 확인 → **"머지해"** 하면 PR·병합 → 운영 확인
5. 인스타그램·쓰레드용 이미지 ZIP(호별)과 게시글 정리

## 약속(합의된 운영 규칙)
- 주제는 **사용자가 고른다**. 최종 시안도 **사용자가 검수**한다. 확정된 문구·숫자는 임의로 고치지 않는다.
- **"머지해"라고 말하기 전에는 `main` 병합·PR 을 하지 않는다.**
- 사실 확인이 안 된 내용은 카드에 쓰지 않고, **확인 못 한 항목은 보고서에 그대로 적는다.**
- 종목·금융상품 추천, 수익 보장, 투자 권유로 읽히는 표현을 쓰지 않는다. 법률·세무 판단은 하지 않는다(최종 확인은 공식 기관·전문가).
- 카드 속 숫자는 **계산 엔진 값만** 쓴다(손으로 옮겨 적지 않기).

## 운영 중 알아둘 것
- **환율이 들어간 호(No.2)** 는 기준일이 지나면 숫자가 낡는다. 게시 직전에 다시 빌드·반영한다.
- **No.3 연말정산** 은 국세청 원문 대조가 되지 않은 항목(카드 3~4 수치는 정책브리핑 한 곳 근거)과 작년(2025년 귀속) 기준 한도 수치(카드 5)가 있다 — 발행 전 운영자 확인 항목으로 남아 있다.
- 호가 늘어도 페이지·메인 배너(최신 3개 호)·지난 호 목록은 `brief.json` 에서 자동으로 따라간다. 이미지는 호당 약 0.7MB.
- 카드 문제가 발견되면 해당 카드만 수정해 `publish.py --replace` 로 교체한다. 독자 제보 채널은 확대 화면의 "오류 알려주기"(독자 오픈채팅).
