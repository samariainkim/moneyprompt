# 장애 기록: Vercel 배포 일시 중지 (2026-11-20)

## 1. 한 줄 요약
Hobby(무료) 팀 `HITS Brand Lab` 의 **CDN(Edge) 요청이 무료 한도 100만 건의 4.6배(460만 건)** 를 넘어 Vercel 이 팀의 배포를 **2026-11-20 부터 12-20 까지** 중지했다. donbuff.com 전체가 402(`DEPLOYMENT_DISABLED`)로 응답했다.

## 2. 확인된 사실
| 항목 | 내용 | 출처 |
|---|---|---|
| 사유 | `Paused for Edge Requests. Your team exceeded the Hobby fair use limits.` / 해제일 2026-12-20 (약 29일) | Vercel 대시보드 팀 화면 |
| 사용량(팀 합계) | CDN 요청 4.6M / 1M, 함수 호출 672K / 1M, Active CPU 1h59m / 4h | 대시보드 Usage |
| 경고 이력 | 사용률 경고 알림이 여러 번(…%, 131%, 459%). 131% 알림은 11/19 오전, 459% 는 11/20 오전 | 대시보드 Inbox |
| 팀 구성 | 같은 팀에 **프로젝트 2개**: `moneyprompt`(donbuff.com), `hitsbrandlab`(hitsbrandlab.com). 한도·정지가 팀 단위라 **두 사이트가 함께 멈춘다** | 대시보드 |
| 함수 호출 | 12시간 10.6만 건 중 거의 전부 `/api/me` (5분당 약 800건, 24시간 일정) | Observability › Functions |

## 3. 아직 모르는 것 (원인 후보)
- **접속 주체**: 헤드리스 브라우저 수집기 / 모니터링·SEO 도구 / 앱 웹뷰 반복 새로고침 / 실제 사용자 급증 중 무엇인지. 24시간 일정한 모양이라 자동화가 유력.
- **시작 시점**: 11/18 대규모 공개(헤더·푸터 개편, `/book/`, DSR 계산기, MONEY BRIEF No.5) 이후로 보이나, 7일 그래프(Pro 전용)가 없어 확정 못 함. 블로그 1편(11/19 17시)보다 먼저 경고가 왔으므로 블로그는 원인이 아닐 가능성이 큼.
- 확인 방법: GA4(페이지·소스·국가·브라우저 7일 추이), Vercel Usage 의 경로별 상위 사용량, (Pro 전환 후) Observability Query 의 Request Path·User-Agent·Country·IP·Referrer 그룹.

## 4. 이미 반영한 조치
- `/api/me` 는 로그인 쿠키가 있을 때만 호출(PR #37). 쿠키 없는 방문의 함수 호출 제거. **CDN 요청 수는 줄지 않는다**(정지 원인인 항목은 그대로).

## 5. 복구 절차
**선택지**
1. **Pro 로 업그레이드(권장)**: 정지가 즉시 해제되는 것이 일반적. 팀 단위이므로 `hitsbrandlab.com` 도 같이 복구된다. 상업 사이트이므로 Hobby 약관상으로도 Pro 가 맞다.
2. 기다리기: 12-20 까지 약 29일 중단. 책 홍보 사이트라 비권장.
3. 호스팅 이전: 별도 작업(이전·DNS 전환·검증)이 크고 시간이 걸린다. 장기 대안으로만 검토.

**Pro 전환 순서 (결제 전에 상한부터)**
1. Vercel › 팀 › Settings › **Billing › Spend Management** 에서 **월 지출 상한**을 정한다(예: 30달러) → "상한 도달 시 프로젝트 일시 중지" 선택, 알림 이메일 켜기. 기본 상한이 높게 잡혀 있을 수 있으니 직접 낮출 것.
2. Pro 로 업그레이드.
3. 사이트 복구 확인: `node web/scripts/check-site.mjs` (모두 ✓ 면 정상).
4. 요청이 계속 늘어나는지 Usage 에서 **첫 1~2시간** 지켜본다. 그대로 초당 2~3건이면 6번(차단)을 서두른다.
5. **원인 확인**(복구 직후 Pro 의 7일 그래프·Query 사용): Request Path / User-Agent / Country / IP·ASN / Referrer 별 상위 값.
6. 출처가 특정되면 Firewall 에 해당 조건 한정 규칙(Rate Limit 또는 Challenge) 추가. 근거 없이 넓게 막으면 검색 로봇·실제 방문자도 막힌다.

**요금 감각**: Pro 는 포함 사용량(월 Edge 요청 1천만 건 수준)을 넘으면 초과분이 과금된다. 이번 속도(일 150~270만 건)가 한 달 이어지면 초과 요금이 수십~백 달러대가 될 수 있다. 단가·포함량은 결제 화면 기준으로 확인할 것.

## 7. 교훈
- 무료 요금제의 한도는 **팀 합계**이고 초과하면 **배포가 한 달 중지**된다. 경고(80%→131%→459%)가 며칠 전부터 와 있었으나 알림을 놓쳤다 → 알림 채널 정비가 가장 값싼 예방책.
- 함수 호출 최적화만으로는 CDN 요청 한도를 지킬 수 없다. 정지 사유 항목(Edge Requests)을 기준으로 지표를 봐야 한다.
