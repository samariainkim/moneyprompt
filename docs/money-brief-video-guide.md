# MONEY BRIEF 유튜브 영상(쇼츠·롱폼) 제작 지침

카드뉴스 한 호를 유튜브 영상으로 만드는 방법. 사람이 읽는 요약이고, Claude 가 따르는 상세 절차는 `.claude/skills/money-brief-shorts/SKILL.md`, `.claude/skills/money-brief-longform/SKILL.md`, 공용 도구는 `.claude/skills/money-brief-video-common/` 에 있다. 채널: **@사마리아인TV**(얼굴 출연 없이 화면 설명 + 더빙 + 자막).

## 한 줄 사용법 — 두 단계
Claude 에게 **"머니브리프 유튜브 쇼츠 영상 제작해줘"** 또는 **"머니브리프 유튜브 롱폼 영상 제작해줘"**(+ 대상 호)라고 하면 해당 스킬이 **두 단계**로 진행한다.

**1단계: 기획 + 제작 세트 → 최종 컨펌 요청까지만** (영상은 만들지 않는다)
1. Claude: 확정·게시된 카드뉴스 호의 내용으로 **최종 기획안**(제목·썸네일 문구·장면 구성·핵심 숫자와 근거·확인 못 한 것·컨펌 항목)과 **제작 세트**(대본, 장면별 TTS 입력 대본, TTS 지시문, 자막 가안, 정지 화면 시안, 업로드 자료 초안, 만드는 방법, 준비할 파일 목록)를 전달하고 **컨펌을 요청**한 뒤 멈춘다.
2. 사용자: 검토·수정 요청(수정되면 Claude 가 다시 컨펌 요청). 컨펌 후 **Google AI Studio TTS 로 더빙**(장면별 wav 권장) + 배경음악 mp3 등 **필요한 파일 준비**.

**2단계: 최종 영상 제작** (사용자가 **"최종 영상 제작"을 요청했을 때만**; 파일이 업로드됐다는 이유만으로는 시작하지 않는다)
3. Claude: 음성 쉼 분석으로 장면·자막 시간 맞춤 → 애니메이션 렌더 → 자막·배경음악(자동 낮춤)·끝 화면(구독/좋아요 버튼) → **MP4·SRT·확인 프레임** 보고
4. 사용자: 시청·검수 → Claude: 수정 반영 → **업로드 자료 확정**(제목·썸네일 문구·설명란·챕터·고정 댓글)
5. 사용자가 유튜브에 직접 게시

## 규격
| | 쇼츠 | 롱폼 |
|---|---|---|
| 화면 | 1080×1920 (9:16) | 1920×1080 (16:9) |
| 길이 | 약 50~60초 | 약 3:30~4:00 |
| 장면 | 6 + 끝 화면 | 9 + 끝 화면 |
| 음향 | 나레이션 + 배경음악(말할 때 자동으로 낮춤), -14 LUFS | 같음 |
| 자막 | 영상에 입힘 + 별도 srt | 같음 |
| 끝 화면 | "돈버프에서 자세한 내용을 확인해보세요" + 구독/좋아요 버튼이 눌리는 연출 | 같음 |

## 약속(합의된 운영 규칙)
- 영상 내용은 **이미 확정·게시된 카드뉴스 호**의 검증된 사실·계산 엔진 숫자만 쓴다. 카드에 없는 주장·숫자는 쓰지 않는다.
- 영상에 **발행일·기준일을 쓰지 않는다**(제도의 적용 기간은 쓴다). 면책은 영상 안과 설명란 양쪽에.
- 상품·금융사 추천, "모르면 큰일" 같은 공포·단정 제목은 쓰지 않는다(질문형·정보형).
- 확정된 문구·타이밍은 임의로 고치지 않는다. 확인 못 한 항목(어긋날 수 있는 자막 구간, 음원 조건 등)은 보고에 그대로 적는다.
- 영상·음성 파일은 저장소에 올리지 않는다(작업 폴더). 스킬·도구 변경의 병합은 **"머지해"** 후에만.
- 배경음악 사용 조건, 합성 음성(AI 음성) 공개 항목은 사용자가 확인한다.

## 알아둘 한계
- 나레이션을 한 파일로 주면 **장면 경계는 정확**하지만 장면 안의 자막 줄 경계가 1초 안팎 어긋날 수 있다. **장면별 음성(S01.wav…)** 을 주면 정확하다.
- 제도 적용 기간이 있는 호(예: 스트레스 금리 6월·12월 고시)는 기간이 지나면 갱신본이 필요하다.
